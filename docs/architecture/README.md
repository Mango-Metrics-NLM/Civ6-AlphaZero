# Architecture

Canonical architecture documentation for Civ6 AlphaZero.

- [`C4_ARCHITECTURE.md`](C4_ARCHITECTURE.md) — the C4 model (context, containers,
  components) for the training/inference system. This is the single canonical
  architecture reference; earlier duplicate copies now redirect here (see
  [`../archive/`](../archive/)).
- [`adr/`](adr/) — Architecture Decision Records.

## Architecture Decision Records

ADRs capture significant, hard-to-reverse decisions and their rationale. Each ADR
has a status lifecycle: **Proposed → Accepted → Superseded/Deprecated**. See
[`adr/README.md`](adr/README.md) for the index.
