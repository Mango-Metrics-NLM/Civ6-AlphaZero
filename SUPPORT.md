# Support

Need help with Civ6 AlphaZero? Here is where to look.

- **Documentation** — start at [`README.md`](README.md) and the
  [documentation index](docs/README.md).
- **How something works** — [`docs/MODULE_REFERENCE.md`](docs/MODULE_REFERENCE.md)
  and [`docs/architecture/C4_ARCHITECTURE.md`](docs/architecture/C4_ARCHITECTURE.md).
- **Questions & discussion** — open a GitHub Discussion, or a GitHub Issue using
  the question/feature template.
- **Bugs** — open a GitHub Issue with the bug template (include repro steps,
  version, and config).
- **Security** — see [`SECURITY.md`](SECURITY.md); report privately.

Please search existing issues before opening a new one.
