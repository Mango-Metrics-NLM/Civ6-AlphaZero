# Support

Need help with Civ6 AlphaZero? Here is where to look.

- **Documentation** — start at [`README.md`](README.md) and the
  [documentation index](docs/README.md), which labels every page by audience
  and tells you what has and has not been validated.
- **How something works** — [`docs/MODULE_REFERENCE.md`](docs/MODULE_REFERENCE.md)
  and [`docs/architecture/C4_ARCHITECTURE.md`](docs/architecture/C4_ARCHITECTURE.md).
- **Running the live Civilization VI bridge** — [`docs/LIVE_CIV6.md`](docs/LIVE_CIV6.md)
  (demo-grade; read its *Known limitations* first).
- **Questions** — open a GitHub Issue with the **Question** template. There is
  no separate discussion forum.
- **Bugs** — open a GitHub Issue with the **Bug report** template (include
  reproduction steps, the distribution version, the commit SHA, and your
  config).
- **Feature ideas** — the **Feature request** template; substantive changes go
  through an OpenSpec proposal (see [`CONTRIBUTING.md`](CONTRIBUTING.md)).
- **Security** — see [`SECURITY.md`](SECURITY.md); report privately, never in
  an issue.

Please search existing issues before opening a new one. This project has a
single maintainer; response times are best-effort.
