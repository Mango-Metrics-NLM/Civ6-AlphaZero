# The play path (plan section 6, LF-D8): code that changes how a fixed network
# plays, so a change to any of it since an evidence run's commit makes that run
# stale. scripts/verify_release_evidence.py requires
#   git diff --name-only <run git_sha> <rc_sha> -- <these pathspecs>
# to be empty for every component run of a release evidence bundle.
#
# One git pathspec per line, matched with the :(glob) magic: `**` spans
# directories, anything else is a literal path from the repository root.
# Blank lines and lines starting with # are ignored.
# tests/scripts/test_verify_release_evidence.py fails if a literal path or a
# glob's directory does not exist, so a rename cannot silently drop coverage.
# tests/scripts/test_release_play_path_closure.py fails if a module that the A1
# training or benchmark code imports is neither listed here nor exempted there
# with a reason, so a new import cannot silently fall outside the list.
